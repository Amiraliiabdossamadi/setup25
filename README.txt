مکسنت
=====
ساخت فایل نصب (Setup.exe):
  روش ۱ (روی ویندوز): Node.js را نصب کنید و build.bat را اجرا کنید -> dist\MaxNet-Setup.exe
  روش ۲ (بدون نصب چیزی): پوشه پروژه را در یک مخزن خصوصی GitHub بگذارید، در تب Actions گزینه "Build MaxNet installer" را اجرا کنید و فایل MaxNet-Setup را دانلود کنید.
فایل MaxNet-Setup.exe را به هر کسی بدهید؛ مراحل نصب (قوانین، انتخاب مسیر، شورتکات) را طی می‌کند و کد پروژه به او داده نمی‌شود.
بعد از نصب در تنظیمات برنامه، آدرس صفحه آپلود روی هاست و کلید API را وارد کنید.

عکس‌ها: ابتدا نسخه سبک ارسال می‌شود (سرعت بالا)، بعد نسخه اصلی در پس‌زمینه می‌رسد و در پوشه مشتری جایگزین می‌شود.
